# 🤖 AI-генератор заданий для Stepik на Python

Инструмент для автоматического создания интерактивных учебных заданий с помощью AI и подготовки их в формате, совместимом со Stepik.

Проект помогает **преподавателям, авторам онлайн-курсов и разработчикам образовательных платформ** быстрее создавать учебный контент, не формируя вручную большое количество JSON-объектов и не тратя время на однотипное оформление заданий.

## 🎯 Что даёт проект

Если вы создаёте курс на Stepik и вам нужно подготовить десятки или сотни заданий, проект позволяет автоматизировать значительную часть этой работы.

С его помощью можно:

* 🤖 генерировать учебные задания с использованием AI;
* 🧩 создавать интерактивные задачи разных типов;
* 📈 выстраивать задания с постепенным увеличением сложности;
* 🎯 формировать задания на основе конкретной темы или учебного модуля;
* 📝 использовать реальные ситуации и практические сценарии;
* 💡 автоматически добавлять подсказки, помогающие учащемуся самостоятельно найти решение;
* 📦 получать структурированный JSON, подготовленный для дальнейшего использования в Stepik;
* ⚙️ автоматизировать рутинную подготовку образовательного контента;
* 🔄 использовать собственные промпты и шаблоны генерации;
* 🌐 работать с генератором через веб-интерфейс.

Таким образом, проект можно использовать как основу для собственного **AI-инструмента подготовки учебных материалов**.

## 🚀 Что умеет генератор

Проект ориентирован на создание последовательности интерактивных заданий.

Например, для темы курса можно сформировать сценарий:

```text
Миссия 1 → Миссия 2 → Миссия 3 → ... → Миссия 10
```

При этом задания могут переходить от более простых к более сложным.

AI получает описание модуля и темы и формирует задания с учётом заданных правил.

---

## 🧩 Поддерживаемые типы заданий

### 1. Choice — выбор ответа

Подходит для проверки понимания теории и принятия решений.

У задания могут быть:

* варианты ответов;
* правильный ответ;
* подсказка;
* HTML-оформление;
* обратная связь.

Пример сценария:

> 🧠 Какой подход лучше использовать для устранения дублирования кода?

---

### 2. Matching — сопоставление

Позволяет связать понятия с определениями, технологиями с назначением или проблемами с решениями.

Например:

```text
Рефакторинг        → Изменение внутренней структуры кода
Дублирование       → Повторяющийся фрагмент программы
Плохое имя         → Имя не отражает назначение объекта
```

Такой формат особенно полезен для терминологии и проверки понимания взаимосвязей.

---

### 3. Sorting — сортировка

Используется там, где важно проверить понимание последовательности действий.

Например:

```text
1. Найти проблемный участок
2. Внести изменения
3. Сохранить исходное поведение
4. Запустить тесты
```

Это позволяет создавать задания не только на запоминание, но и на понимание процесса.

## 🤖 AI и Prompt Engineering

Одна из ключевых частей проекта — управление результатом генерации через специальный промпт.

В промпте можно определить:

* 📚 название учебного модуля;
* 🎯 тему;
* 🔢 количество заданий;
* 📈 порядок усложнения;
* 🧩 допустимые типы заданий;
* 📝 структуру текста;
* 💡 правила создания подсказок;
* 🎨 требования к HTML-разметке;
* 📦 формат итогового JSON.

Например:

```text
Модуль: Рефакторинг кода
Тема: Улучшение существующего проекта

Создать последовательность интерактивных заданий.
Начать с choice, затем использовать matching
и завершить заданиями sorting.

Сложность должна постепенно увеличиваться.
```

Такой подход позволяет не просто получать случайные ответы AI, а задавать **структуру и правила формирования учебного контента**.

## 📦 Формат результата

Генератор формирует структурированные JSON-объекты.

Например:

```json
{
  "block": {
    "name": "choice",
    "text": "<h3>Миссия 1</h3>...",
    "source": {
      "options": [
        {
          "is_correct": true,
          "text": "Правильный вариант",
          "feedback": ""
        }
      ]
    }
  }
}
```

Структура содержит необходимые данные для последующего использования задания в образовательном сценарии.
